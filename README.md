# student-housing-management-system
這是一個使用 Python 開發的學生租屋資訊管理系統。

本專案起源於資訊管理課程中的學生租屋平台構想。在自主學習 Python 後，我嘗試將原本停留於介面與功能規劃的構想，逐步轉化為可實際操作的 Python 系統，並透過專案實作培養程式設計與問題解決能力。

專案動機

過去的學習背景主要以企業管理與財務金融為主，在接觸資訊管理與資料分析相關課程後，我開始對資訊科技如何協助解決實際問題產生興趣。
因此，我從Python基礎程式設計開始自主學習，並選擇學生租屋情境作為實作主題，將函式、迴圈等概念整合至一個完整的小型專案中。

系統功能

房源管理
　新增房源
　修改房源
　刪除房源
　房源編號查詢
　顯示所有房源
 
房源搜尋
　依租金區間搜尋
　租金由低至高／由高至低排序
　依房型搜尋
　依地區搜尋
　租金、房型及地區多條件篩選
 
資料驗證
　正整數輸入驗證
　手機及市話格式驗證
　房型輸入驗證
　日期格式驗證
 
資料管理
　JSON資料儲存
　JSON資料讀取
　房源編號自動產生
